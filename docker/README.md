# links

Static link-in-bio site for jsisques, built with Astro. Served by nginx. No backend, no
database.

## Quick start

```bash
docker run -p 8080:8080 jsisques/links:latest
```

Then open http://localhost:8080.

## Ports

| Port | Purpose             |
| ---- | ------------------- |
| 8080 | HTTP (static site)  |
